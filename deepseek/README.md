# 臭蛆跳一跳

一条有梦想的臭蛆，在发霉的下水道平台之间蹦跶。

## 操作
- 按住屏幕 / 空格蓄力，松开起跳
- 落在平台中心触发「完美」，连击加分
- 掉进臭水沟游戏结束，最高分保存在浏览器本地

## GitHub Pages 部署
1. 新建一个 Public 仓库，例如 `maggot-jump`
2. 把本目录的 `index.html`（和可选的 `.nojekyll`）上传到仓库根目录
3. 仓库 Settings → Pages → Build and deployment
4. Source 选择 “Deploy from a branch”，Branch 选 `main`，目录选 `/ (root)`，保存
5. 等待 1–2 分钟，访问 `https://<你的用户名>.github.io/maggot-jump/`

单文件、无外部依赖，打开即可玩。
